3.kubectl commmandline install:
*******************************
  install the kubectl from official website  and config  k8s cluster

  1.cat the admin.conf from k8s cluster
    sudo cat /etc/kubernetes/admin.conf --> for short config --> copy the admin.conf --> create .kube/config file  from workstation--> paste admin.conf-->folow 7 & 8 steps 
  2.save this admin.conf into your workstation as kubeadm-config.yaml
  3.Take a backup of the existing kubeconfig
    cp ~/.kube/config ~/.kube/config.bak
  4.Merge the default config with kubeadm-config.yaml and export it to KUBECONFIG variable
    export KUBECONFIG=~/.kube/config:/path/to/kubeadm-config.yaml
  5.Merger the configs to a file
    kubectl config view --flatten > ~/.kube/merged_config.yaml
  6.Replace the old config with the new config
    mv ~/.kube/merged_config.yaml ~/.kube/config
  7.List all the contexts 
    kubectl config get-contexts -o name
  8.Set the current context to the kubeadm cluster.
    kubectl config use-context <cluster-name-here>

Jenkins slowness:
-----------------
What is the root cause of the issue?
========================================
If you are using AWS free tier account and creating EC2 instance without using Elastic IP. 
If you are stopping EC2 instance and restarting EC2, this would have new IP after every restart, 
Jenkins was trying to use old IP address when you are trying to start Jenkins. 
Due to this issue, Jenkins will be very slow.


Pre-requisites:
---------------------
Jenkins is setup in AWS cloud using free-tier account.
There are two ways you can fix this issue:

First option using command line
--------------------------------
1.cd /var/lib/jenkins/

Modify jenkins.model.JenkinsLocationConfiguration.xml file by executing below command:

2.sudo vim jenkins.model.JenkinsLocationConfiguration.xml

Make sure you provide Jenkins current URL in below location and restart Jenkins.

3.sudo service jenkins restart

2.Second option is using Jenkins UI
----------------------------------------------
1.Change public URL under Manage Jenkins->System
2.Change Jenkins URL to current Jenkins URL:
